This project focuses on sales prediction in knowledge-sharing live streaming e-commerce with book-related streams as the application context. The study is grounded in social support theory and leverages large language models (LLMs) to build a live streaming sales prediction framework. The supplementary materials provide LLM prompt templates, fine-tuning parameters, and non-LLM model parameters.
We provide a subset of data examples. For privacy protection and collaborative agreement constraints, and because follow-up research is ongoing, the full dataset is not publicly available.
